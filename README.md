# Relatório da turma

Exemplo de estudo desenvolvido com assistência do Codex para a atividade de Algoritmos e Programação. As versões em Python e Java leem os nomes e as notas, calculam as médias individuais e da turma e mostram a situação de cada aluno e o total de aprovados e reprovados.

As notas vão de 0 a 10 e aceitam vírgula ou ponto como separador decimal. A média mínima para aprovação é 7,0. A média da turma é a média aritmética das médias individuais.

## Executar

Python 3

```sh
python relatorio_turma.py
```

Java 8 ou mais recente

```sh
javac -encoding UTF-8 RelatorioTurma.java
java RelatorioTurma
```
